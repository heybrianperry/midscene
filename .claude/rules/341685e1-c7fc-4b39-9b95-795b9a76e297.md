<rule_activation id="341685e1-c7fc-4b39-9b95-795b9a76e297" title="Adopt Playwright for E2E Testing of Frontend Rendering Models: Frontend Rendering Model" applies_to="**/*">
These rules are ALWAYS ACTIVE for all frontend rendering model implementations and web-based components requiring browser rendering validation.
</rule_activation>

### Rules

- **R-PLAYWRIGHT-001** MUST: All frontend rendering model implementations MUST include Playwright-based E2E tests that verify rendering behavior in real browser contexts.

### Verify

```bash
# Check for Playwright test files
find . -name '*.spec.ts' -path '*/playwright/*' | wc -l | grep -v '^0$'

# Verify @playwright/test dependency
grep -r "@playwright/test" package.json packages/*/package.json

# Verify test scripts reference Playwright
grep -r "test.*playwright" package.json packages/*/package.json | grep -E '(test|e2e)'
```

**Accept when:**
- At least one Playwright test file exists in the project with .spec.ts extension
- Package.json includes @playwright/test as a dependency
- Test scripts reference Playwright for E2E testing execution
- E2E tests are organized in dedicated directories (e.g., tests/ai/web/playwright/)
- Test files use descriptive names indicating the rendering scenario being validated

<enforcement>
Claude Code MUST NOT skip or defer verification of Playwright E2E test presence for frontend rendering components. Violations require architectural review approval with documented justification.
</enforcement>
