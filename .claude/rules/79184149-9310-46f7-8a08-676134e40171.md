### Rules

- **R-PW-001** MUST: All browser-based UI rendering tests MUST use Playwright as the primary testing framework.
- **R-PW-002** MUST: All web-based UI component testing MUST use Playwright.
- **R-PW-003** MUST: Browser rendering verification tests MUST use Playwright.
- **R-PW-004** MUST: Web integration test suites MUST use Playwright.
- **R-PW-005** MUST: Screenshot and visual regression testing MUST use Playwright.
- **R-PW-006** MUST: Storage state and navigation testing MUST use Playwright.
- **R-PW-007** MUST: Cache functionality verification MUST use Playwright.
- **R-PW-008** MUST: Cross-browser compatibility tests MUST use Playwright.
- **R-PW-009** SHOULD: Structure test files using *.spec.ts naming convention in appropriate test directories.
- **R-PW-010** SHOULD: Implement CDP fallback patterns for screenshot functionality to handle edge cases.
- **R-PW-011** SHOULD: Use Playwright's storage state APIs for testing navigation and persistence scenarios.
- **R-PW-012** SHOULD: Configure Playwright test runner with appropriate timeouts, retries, and browser contexts.
- **R-PW-013** SHOULD: Leverage Playwright's built-in assertions and expect matchers for cleaner test code.

### Verify

```bash
# Verify Playwright imports in test files
grep -r "@playwright/test" packages/*/tests --include="*.ts" --include="*.js"

# Find Playwright test files by naming convention
find packages -name "*.spec.ts" -path "*/playwright/*" -type f

# Verify Playwright API usage patterns
grep -r "page\.goto\|page\.screenshot\|browserContext" packages/*/tests --include="*.spec.ts" | head -20
```

**Accept when:**
- All web integration test files import from '@playwright/test' and use Playwright APIs
- Test files follow naming convention (*.spec.ts) and are organized in appropriate test directories
- Screenshot tests implement CDP fallback mechanisms and storage/navigation tests verify state persistence
- CI/CD pipeline successfully executes Playwright tests across multiple browser contexts

Claude Code MUST NOT skip or defer verification. All browser-based UI rendering tests MUST use Playwright. Violations are flagged during code review and CI/CD pipeline checks.
