<rule_activation id="38bf4c8f-8987-4ff8-b312-240666614a23" title="Standardize Test File Naming with .test.ts Extension for TypeScript Tests" applies_to="**/*.test.ts">
These rules are ALWAYS ACTIVE for all TypeScript test files in the codebase. All test discovery, execution, and tooling configurations must recognize and process .test.ts files.
</rule_activation>

### Rules

- **R-TEST-001** MUST NOT: Test files MUST NOT use alternative extensions such as .spec.ts, .test.tsx, or _test.ts unless explicitly documented as exceptions.

### Verify

```bash
# Count .test.ts files in repository
find . -type f -name '*.test.ts' | wc -l

# Check for non-compliant test file extensions
find . -type f \( -name '*.spec.ts' -o -name '*_test.ts' \) -not -path '*/node_modules/*' | wc -l

# Verify test runner configurations include .test.ts pattern
grep -r 'testMatch.*\.test\.ts' --include='*.config.{js,ts}' .
```

**Accept when:**
- All TypeScript test files in the repository use .test.ts extension (verify command 1 returns count > 0, command 2 returns 0)
- Test runner configurations explicitly include **/*.test.ts pattern (verify command 3 finds matches)
- No test files with alternative extensions (.spec.ts, _test.ts) exist outside documented exceptions
- CI/CD pipeline successfully discovers and executes all tests using .test.ts glob pattern

<enforcement>
Claude Code MUST verify test file naming compliance before accepting TypeScript test files. Violations of R-TEST-001 must be flagged and corrected unless an approved exception is documented.
</enforcement>
