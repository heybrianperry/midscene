These rules are ALWAYS ACTIVE for all test files matching `**/*.test.ts` across the monorepo.
</rule_activation>

### Rules

- **R-VITEST-001** MUST: All test files MUST use Vitest as the test framework and follow the .test.ts naming convention
- **R-VITEST-002** MUST: All test files MUST import test utilities (describe, test, expect) from the 'vitest' package
- **R-VITEST-003** MUST: Test files MUST be organized in tests/ directories with unit and integration subdirectories
- **R-VITEST-004** MUST: A vitest.config.ts or vite.config.ts file with test configuration MUST exist in the project
- **R-VITEST-005** SHOULD: Use Vitest's workspace feature for monorepo configurations to enable per-package test configuration while maintaining shared defaults
- **R-VITEST-006** SHOULD: Maintain a shared test setup file (e.g., tests/setup.ts) that configures Vitest globals, mocks, and environment variables for all packages
- **R-VITEST-007** SHOULD: Establish test isolation guidelines and use proper setup/teardown hooks to support concurrent test execution

### Verify

```bash
# Verify Vitest imports in test files
grep -r "from 'vitest'" --include='*.test.ts' || grep -r 'from "vitest"' --include='*.test.ts'

# Verify Vitest configuration exists
find . -name 'vitest.config.*' -o -name 'vite.config.*' | xargs grep -l 'test'

# Verify test utilities usage
grep -r "describe\|test\|it\|expect" --include='*.test.ts' | head -5

# Verify test file naming convention
find . -path ./node_modules -prune -o -name '*.test.ts' -type f -print

# Run Vitest in CI/CD mode
vitest run --reporter=verbose --coverage
```

**Accept when:**
- All test files import test utilities (describe, test, expect) from 'vitest' package
- A vitest.config.ts or vite.config.ts file exists with test configuration
- Test files follow the .test.ts naming convention and are organized in tests/ directories
- CI/CD pipeline executes 'vitest run' command successfully with no test failures
- Test coverage meets configured thresholds

Claude Code MUST NOT skip or defer verification. All test files MUST comply with R-VITEST-001 through R-VITEST-007. Violations block CI/CD pipeline merges and require code review corrections or documented exceptions with architecture review board approval.
