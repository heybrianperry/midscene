<rule_activation id="12c07629-814f-4a3f-b52e-2c90833c6143" title="Standardize console.log for Development Logging and Debugging: Log Sensitive Information" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files matching `**/*`. Console logging is the standardized development logging mechanism across browser extensions, CLI tools, visualizer components, and build scripts. All console.log usage must comply with sensitive data protection requirements.
</rule_activation>

### Rules

- **R-CONSOLE-001** MUST_NOT: Log sensitive information such as authentication tokens, passwords, or personally identifiable information (PII) through console methods.

### Verify

```bash
# Count total console.log statements across codebase
grep -r 'console\.log' apps/chrome-extension/src packages/cli/src packages/visualizer/src packages/recorder/src --include='*.ts' --include='*.tsx' | wc -l

# Audit for sensitive data patterns in console.log statements
grep -r 'console\.log.*password\|console\.log.*token\|console\.log.*secret' . --include='*.ts' --include='*.tsx' || echo 'No sensitive data logging detected'

# Verify production builds strip console output
npm run build 2>&1 | grep -i 'console' || echo 'Build completed without console warnings'
```

**Accept when:**
- Console.log statements are present in detected files (chrome-extension, CLI, visualizer, recorder, build scripts) for development debugging purposes
- No console.log statements contain obvious sensitive information patterns (passwords, tokens, secrets, API keys)
- Production builds either strip console statements or include only intentional operational logging with documented justification
- Code review process has verified no sensitive data is logged to console
- Build configuration confirms production builds minimize or eliminate console output

<enforcement>
Claude Code MUST verify all console.log statements comply with R-CONSOLE-001 before approving code changes. Violations containing sensitive information must be flagged immediately. Verification is mandatory and cannot be deferred.
</enforcement>
