<rule_activation id="ea590866-3746-477e-9495-fbb8368c2cc9" title="Standardize Vitest Configuration for Runtime Config Sources in CI/CD: Shared Test Configurations" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files matching test configurations, Vitest config files, and CI/CD pipeline definitions across the monorepo.
</rule_activation>

### Rules

- **R-VITEST-001** SHOULD: Shared test configurations SHOULD be extracted to a common package to promote reusability across the monorepo.
- **R-VITEST-002** MUST: All packages containing tests MUST include a vitest.config.ts file at their root level.
- **R-VITEST-003** MUST: Runtime configuration sources MUST be explicitly defined and documented in each vitest.config.ts file.
- **R-VITEST-004** SHOULD: Packages SHOULD use TypeScript's 'extends' or Vitest's configuration merging to customize while maintaining base standards.
- **R-VITEST-005** MUST: CI/CD pipelines MUST validate presence of vitest.config.ts files before running tests.
- **R-VITEST-006** MUST: Test execution in CI/CD pipelines MUST use standardized Vitest configurations.

### Verify

```bash
# Verify all packages have vitest.config.ts files
find . -name 'vitest.config.ts' -type f | grep -E '(packages/[^/]+/vitest.config.ts)' || echo 'Missing vitest.config.ts files'

# Verify Vitest imports in configuration files
grep -r "import.*vitest" packages/*/vitest.config.ts | wc -l

# Validate test execution with standardized configuration
npm run test -- --reporter=json 2>&1 | jq '.success' || echo 'Test execution validation failed'
```

**Accept when:**
- All packages contain a vitest.config.ts file at their root level
- Test execution in CI/CD pipelines uses the standardized Vitest configurations
- Runtime configuration sources are explicitly defined and documented in each vitest.config.ts file
- CI/CD pipeline checks validate presence and structure of vitest.config.ts files before running tests
- Static analysis confirms configuration file structure meets required standards

<enforcement>
Claude Code MUST NOT skip or defer verification. All vitest.config.ts files MUST be validated against these rules before accepting changes to test infrastructure or CI/CD pipeline configurations.
</enforcement>
