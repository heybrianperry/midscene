<rule_activation id="2cc8b58e-e3cb-4861-a4db-411b01cd628f" title="Standardize Unit Test Structure with Vitest for TypeScript Packages: Test Files Mirror" applies_to="**/*.ts">
These rules are ALWAYS ACTIVE for all TypeScript packages within the monorepo. Unit tests are critical components of CI/CD pipelines and must follow standardized structure and naming conventions.
</rule_activation>

### Rules

- **R-VITEST-001** SHOULD: Test files SHOULD mirror the structure and naming of the source files they test (e.g., playground.ts → playground.test.ts)
- **R-VITEST-002** MUST: All unit tests MUST be located in tests/unit or tests/unit-test directories with .test.ts file extensions
- **R-VITEST-003** MUST: All TypeScript packages MUST have vitest.config.ts or vitest.config.js configured in the package root
- **R-VITEST-004** MUST: Vitest MUST be installed as a dev dependency in each package
- **R-VITEST-005** MUST: Package.json test scripts MUST run 'vitest run' for CI and 'vitest' for local development with watch mode
- **R-VITEST-006** SHOULD: Coverage thresholds SHOULD be set in vitest.config.ts to maintain minimum coverage requirements (e.g., 80% line coverage)
- **R-VITEST-007** MUST: Test execution MUST be integrated into CI/CD pipeline with appropriate failure conditions and reporting

### Verify

```bash
# Count test files in correct directory structure
find packages -name '*.test.ts' -type f | grep -E 'tests/(unit|unit-test)/' | wc -l

# Verify Vitest imports are present in test files
grep -r "from 'vitest'" packages/*/tests/unit*/*.test.ts | wc -l

# Verify vitest.config files exist in package roots
find packages -name 'vitest.config.ts' -o -name 'vitest.config.js' | wc -l
```

**Accept when:**
- All TypeScript packages contain unit tests in tests/unit or tests/unit-test directories with .test.ts extensions
- Vitest imports are present in test files and vitest.config files exist in package roots
- CI/CD pipeline successfully executes test commands and reports results for all packages
- Test coverage reports are generated and meet minimum threshold requirements

<enforcement>
Claude Code MUST verify test structure compliance before approving TypeScript package changes. Violations MUST be flagged: incorrect test file locations, missing vitest.config files, or test coverage below thresholds. CI/CD pipeline checks are mandatory and MUST NOT be skipped.
</enforcement>
