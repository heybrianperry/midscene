<rule_activation id="d08f1474-5add-4ccb-b4a1-a5fc4b659117" title="Standardize Vitest Configuration for Runtime Config Sources in CI/CD: Packages Use Vitest" applies_to="**/*">
These rules are ALWAYS ACTIVE for all packages in the monorepo, particularly those in packages/cli and packages/shared.
</rule_activation>

### Rules

- **R-VITEST-001** MUST: All packages MUST use Vitest as the standard test framework with centralized configuration files.
- **R-VITEST-002** MUST: All packages with tests MUST contain a vitest.config.ts file at their root level.
- **R-VITEST-003** MUST: Runtime configuration sources MUST be explicitly defined and documented in each vitest.config.ts file.
- **R-VITEST-004** MUST: Test execution in CI/CD pipelines MUST use the standardized Vitest configurations.
- **R-VITEST-005** SHOULD: Packages SHOULD use TypeScript's 'extends' or Vitest's configuration merging to customize while maintaining base standards.
- **R-VITEST-006** SHOULD: Vitest versions SHOULD be pinned in shared dependencies to prevent breaking changes across packages.

### Verify

```bash
# Verify all packages have vitest.config.ts files
find . -name 'vitest.config.ts' -type f | grep -E '(packages/[^/]+/vitest.config.ts)' || echo 'Missing vitest.config.ts files'

# Verify vitest imports are present in configuration files
grep -r "import.*vitest" packages/*/vitest.config.ts | wc -l

# Verify test execution succeeds with standardized configuration
npm run test -- --reporter=json 2>&1 | jq '.success' || echo 'Test execution validation failed'
```

**Accept when:**
- All packages contain a vitest.config.ts file at their root level
- Test execution in CI/CD pipelines uses the standardized Vitest configurations
- Runtime configuration sources are explicitly defined and documented in each vitest.config.ts file
- CI/CD pipeline checks validate presence and structure of vitest.config.ts files before running tests

<enforcement>
Claude Code MUST NOT skip or defer verification. All packages MUST pass the verify commands before code is accepted. CI/CD pipeline failures due to missing or non-conformant vitest.config.ts files MUST block pull requests.
</enforcement>
