<rule_activation id="cba392db-f069-4980-95f6-7eaa8744c326" title="Adopt Process Lifecycle Management Pattern for External Service Integration: External Service Integrations" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files that spawn or manage external processes, services, or integrations (XVFB, RDP backends, test servers, Playwright, browser automation, CLI tools managing background services).
</rule_activation>

### Rules

- **R-PLCM-001** SHOULD: External service integrations SHOULD implement cleanup handlers to ensure resources are released on unexpected termination.

### Verify

```bash
# Check for process spawning without cleanup handlers
grep -r "spawn\|exec\|fork" --include="*.ts" --include="*.js" | grep -v "node_modules" | xargs -I {} sh -c 'echo "Checking: {}"; grep -l "terminate\|kill\|cleanup" "{}" || echo "WARNING: No cleanup found"'

# Find all process managers and verify they have stop/terminate/cleanup logic
find . -type f \( -name "*.ts" -o -name "*.js" \) -not -path "*/node_modules/*" -exec grep -l "Process\|Service.*start\|spawn" {} \; | xargs grep -L "stop\|terminate\|cleanup" || echo "All process managers have cleanup"

# Verify lifecycle tests exist
npm test -- --grep "lifecycle|cleanup|shutdown" || echo "No lifecycle tests found"
```

**Accept when:**
- All files that spawn external processes include corresponding termination/cleanup logic
- Integration modules expose consistent start/stop APIs as verified by interface compliance checks
- Lifecycle tests exist for each external service integration covering startup, health check, and shutdown scenarios
- Process signal handlers (SIGTERM, SIGINT) are implemented to ensure cleanup on unexpected termination
- Structured logging exists at key lifecycle events (starting, ready, stopping, stopped, error) with correlation IDs

<enforcement>
Claude Code MUST NOT skip or defer verification of lifecycle management patterns. All external process integrations MUST implement cleanup handlers. Code review MUST verify lifecycle management for any PR introducing external process integration. Violations block PR merge until properly remediated.
</enforcement>
