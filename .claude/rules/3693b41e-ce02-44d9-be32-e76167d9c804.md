<rule_activation id="3693b41e-ce02-44d9-be32-e76167d9c804" title="Standardize console.log for Development Logging and Debugging: Use Console Debug" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files matching `**/*`. Console logging is the standardized approach for development logging and debugging across browser extensions, CLI tools, visualizer components, and build scripts.
</rule_activation>

### Rules

- **R-CONSOLE-001** MAY: Use console.debug for verbose diagnostic information that is typically filtered out in production builds.

### Verify

```bash
# Count console.log usage across codebase
grep -r 'console\.log' apps/chrome-extension/src packages/cli/src packages/visualizer/src packages/recorder/src --include='*.ts' --include='*.tsx' | wc -l

# Audit for sensitive data logging patterns
grep -r 'console\.log.*password\|console\.log.*token\|console\.log.*secret' . --include='*.ts' --include='*.tsx' || echo 'No sensitive data logging detected'

# Verify production builds strip console statements
npm run build 2>&1 | grep -i 'console' || echo 'Build completed without console warnings'
```

**Accept when:**
- Console.log statements are present in detected files (chrome-extension, CLI, visualizer, recorder, build scripts) for development debugging
- No console.log statements contain obvious sensitive information patterns (passwords, tokens, secrets, API keys)
- Production builds either strip console statements or include only intentional operational logging with documented justification
- Build tools (webpack, rollup, terser, babel-plugin-transform-remove-console) are configured to eliminate console output in production
- Environment variables or feature flags conditionally enable verbose logging in development
- Log message prefixes follow naming conventions (e.g., '[StoreName]', '[Worker]', '[Bridge]') for easy filtering

<enforcement>
Claude Code MUST NOT skip or defer verification. All console.log usage must be audited for sensitive data before merge. Production builds must be verified to strip or minimize console output.
</enforcement>
