<rule_activation id="a0ef30da-454d-4443-82a3-51f3a0e4ec05" title="Adopt Vitest as Standard Test Framework for CI/CD Pipeline: Test Files Mirror" applies_to="**/*.test.ts">
These rules are ALWAYS ACTIVE for all test files in the monorepo. Vitest is the standard test framework for all TypeScript test files, with test structure mirroring source code organization.
</rule_activation>

### Rules

- **R-VITEST-001** SHOULD: Test files SHOULD mirror the structure of the source code they test for easy navigation.
- **R-VITEST-002** MUST: All test files MUST import test utilities (describe, test, expect) from the 'vitest' package.
- **R-VITEST-003** MUST: Test files MUST follow the .test.ts naming convention.
- **R-VITEST-004** SHOULD: Tests SHOULD be organized in tests/unit and tests/integration directory structures to clearly separate test types.
- **R-VITEST-005** MUST: A vitest.config.ts or vite.config.ts file with test configuration MUST exist in the project.
- **R-VITEST-006** SHOULD: Shared test setup files (e.g., tests/setup.ts) SHOULD configure Vitest globals, mocks, and environment variables for all packages.
- **R-VITEST-007** MUST: CI/CD pipelines MUST execute 'vitest run' command and fail builds on test failures.
- **R-VITEST-008** SHOULD: Test files SHOULD be properly structured for concurrent execution with proper setup/teardown hooks.

### Verify

```bash
# Verify Vitest imports in test files
grep -r "from 'vitest'" --include='*.test.ts' || grep -r 'from "vitest"' --include='*.test.ts'

# Verify Vitest configuration exists
find . -name 'vitest.config.*' -o -name 'vite.config.*' | xargs grep -l 'test'

# Verify test file patterns
grep -r "describe\|test\|it\|expect" --include='*.test.ts' | head -5

# Verify test file naming convention
find . -path ./node_modules -prune -o -name '*.test.ts' -type f -print

# Verify test directory structure
find . -path ./node_modules -prune -o -type d -name 'tests' -print
```

**Accept when:**
- All test files import test utilities (describe, test, expect) from 'vitest' package
- A vitest.config.ts or vite.config.ts file exists with test configuration
- Test files follow the .test.ts naming convention and are organized in tests/ directories
- Test file structure mirrors the source code structure they test
- CI/CD pipeline successfully executes 'vitest run' without failures
- Shared test setup files are present and properly configured
