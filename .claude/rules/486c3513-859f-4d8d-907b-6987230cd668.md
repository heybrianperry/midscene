### Rules

- **R-CACHE-001** MUST: Public API clients MUST implement a client-side cache layer using browser-native storage mechanisms (IndexedDB, LocalStorage, or SessionStorage).
- **R-CACHE-002** MUST: Use a storage provider abstraction layer to enable swapping storage backends without changing consumer code.
- **R-CACHE-003** MUST: Implement cache keys using a consistent naming convention: 'api:version:endpoint:params' to avoid collisions.
- **R-CACHE-004** MUST: Include cache metadata (timestamp, version, TTL) alongside cached data for effective invalidation.
- **R-CACHE-005** SHOULD: Provide developer tools or debug modes to inspect, clear, and monitor cache state during development.
- **R-CACHE-006** SHOULD: Consider using libraries like idb-keyval or localforage to simplify IndexedDB interactions and provide fallbacks.
- **R-CACHE-007** MUST: Implement encryption for sensitive cached data and exclude authentication tokens from cache.
- **R-CACHE-008** MUST: Implement storage quota monitoring, automatic cache pruning of oldest entries, and graceful degradation to network-only mode.

### Verify

```bash
# Verify IndexedDB, localStorage, or sessionStorage usage in cache/storage contexts
grep -r 'IndexedDB\|localStorage\|sessionStorage' packages/*/src --include='*.ts' --include='*.tsx' | grep -i 'cache\|storage\|provider'

# Verify cache TTL and expiration logic
grep -r 'cache.*TTL\|time.*to.*live\|expir' packages/*/src --include='*.ts' --include='*.tsx'

# Verify storage provider abstractions and cache interfaces
grep -r 'class.*StorageProvider\|interface.*Cache' packages/*/src --include='*.ts' --include='*.tsx'
```

**Accept when:**
- All public API client implementations include a documented cache layer using browser storage APIs
- Cache implementations include explicit TTL configuration and invalidation logic
- Storage provider abstractions exist to decouple cache implementation from consumer code
- Cache keys follow the 'api:version:endpoint:params' naming convention
- Cache metadata (timestamp, version, TTL) is stored alongside cached data
- Sensitive data is encrypted or excluded from cache (authentication tokens)
- Storage quota monitoring and automatic pruning mechanisms are implemented
