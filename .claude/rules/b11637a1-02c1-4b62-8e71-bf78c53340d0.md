These rules are ALWAYS ACTIVE for all files matching the scope: All test files in packages/cli/tests, All test files in packages/shared/tests, Vitest configuration files at package root level, CI/CD pipeline test execution stages, and Runtime configuration loading mechanisms for tests.
</rule_activation>

### Rules

- **R-VITEST-001** MUST: Runtime configuration sources MUST be explicitly defined in vitest.config.ts to ensure deterministic test execution

### Verify

```bash
# Verify vitest.config.ts files exist in all packages
find . -name 'vitest.config.ts' -type f | grep -E '(packages/[^/]+/vitest.config.ts)' || echo 'Missing vitest.config.ts files'

# Verify vitest imports are present in configuration files
grep -r "import.*vitest" packages/*/vitest.config.ts | wc -l

# Validate test execution with standardized configuration
npm run test -- --reporter=json 2>&1 | jq '.success' || echo 'Test execution validation failed'
```

**Accept when:**
- All packages contain a vitest.config.ts file at their root level
- Test execution in CI/CD pipelines uses the standardized Vitest configurations
- Runtime configuration sources are explicitly defined and documented in each vitest.config.ts file
